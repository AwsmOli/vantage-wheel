# Vantage Wheel

A DIY sim racing wheel base — working name "Vantage Wheel".

> Status: early idea, not fleshed out yet.

## Concept

A custom-built direct-drive-style wheel base to pair with the [Button Box](https://github.com/AwsmOli/button-box) sim racing button box. An early ESP32-S3 sketch exploring USB host mode (reading a physical keyboard and re-emitting it as a USB HID device) lives alongside the Button Box firmware for now, at [`code/vantage_wheel.ino`](https://github.com/AwsmOli/button-box/blob/main/code/vantage_wheel.ino), until this project has enough of its own hardware and code to stand on its own.

Details on force feedback approach, motor/driver selection, and the wheel rim itself are still to be worked out.
